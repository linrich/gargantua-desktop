# Gargantua · 卡冈图雅

原生 macOS 桌面黑洞，用 Swift、AppKit、SwiftUI 和 Metal 绘制。黑洞以无边框透明窗口悬浮在桌面上，支持拖动、鼠标穿透，以及可选的桌面引力透镜。

根据公开的 Kerr 黑洞成像研究独立实现，包含旋转黑洞光线积分、椭圆光束滤波和镜头点扩散函数（PSF）卷积。**不是 DNGR 原程序或电影官方产品**；默认盘面材质、镜头响应和桌面扭曲包含艺术化近似。见 [模型与来源](MODEL.md)。

## 系统要求

- macOS 13 或更高版本，支持 Metal 的 Mac。
- 当前验证平台为 Apple Silicon；Intel Mac 尚未验证。
- 从源码构建需要已完成首次启动与许可流程的 Xcode，以及 Python 3。
- 没有第三方软件包、API 密钥或素材下载依赖。

当前源码版本为 **0.9.6**。本仓库的构建脚本面向本地开发，尚未集成 Developer ID 签名与 Apple 公证；不能把自行打包的 ZIP 当作已公证的安装包。

## v0.9.6 更新

在保持分辨率、光束数量、材质精度和完整 PSF 的前提下，优化 PSF 资源布局与大尺寸 FFT、光束缓存按需分配、设置更新、启动资源共享、盘面 EWA 分支和背景事件调度。

同批离屏对照中，3840×2400 整帧 GPU 中位耗时减少 13.86%，宽 PSF 场景减少 17.59%；测试进程峰值内存分别减少 27.07%、24.57%。动态背景 GPU 耗时基本持平。以上是一台 M1 Max 上的生成场景结果，不代表实际显示帧率或整机节电比例；小尺寸实测 PSF 案例首次出现尾延迟回退，追加复测未复现，详见 [性能范围](PERFORMANCE.md)。

## 从源码构建

在终端执行：

```sh
git clone https://github.com/linrich/gargantua-desktop.git
cd gargantua-desktop
zsh Scripts/build.sh
zsh Scripts/package.sh
```

输出：

- `build/Gargantua.app`：应用程序。
- `build/Gargantua-macOS.zip`：应用压缩包。
- `build/Gargantua-macOS.zip.sha256`：校验和，仅包含文件名，可在同目录验证。

建议将 ZIP 解压到一个固定位置，再双击 **Gargantua.app**。部分文件管理环境会为 `.app` 附加 Finder 元数据；打包脚本会排除这些属性，并对解包副本做严格签名检查。升级前先通过菜单栏退出旧实例，避免把不同构建的窗口混在一起。

未创建 `Signing/LocalSigning.plist` 时，脚本使用 ad hoc 签名，不需要作者的证书。此签名适合本地开发，更新后可能需要重新授予录屏权限。需要稳定开发身份时，按 [签名说明](Signing/README.md) 配置自己的证书。脚本不会安装 App、导出私钥、重置权限或自动运行程序。

也可以用 Xcode 打开 `Package.swift` 查看项目；Swift Package 运行方式不会自动采用这里的 App 打包和签名策略。

## 使用

1. 打开 App 后出现控制面板，菜单栏中的黑洞图标可再次打开它。
2. 默认启用鼠标穿透；关闭后可拖动黑洞，双击黑洞区域可打开面板。
3. 关闭面板不会退出 App；通过菜单栏的「退出 Gargantua」或面板电源按钮退出。

主要选项：

- **尺寸**：360 pt 至所在屏幕能容纳的最大尺寸，默认 360 pt。「全屏适配」保留完整盘面比例，不进入独立全屏空间。
- **自旋**：默认 0，范围 −0.998～+0.998。「电影参数」设为 +0.600、仰角 8°、180°快门，并关闭物理频移。
- **流速**：以 760 pt 下 0.05× 为默认基准，随窗口尺寸补偿；可暂停时间。
- **配色**：暖金、冰蓝、紫罗兰、赤焰、银白，以及色相、饱和度调节。
- **画质**：节能、均衡、精细。盘面材质精度随渲染尺寸提升；内部图像最大 3840×2400，较大窗口会受到预算限制。
- **光束与镜头**：可切换椭圆光束抗闪烁和镜头光晕，调节快门、亮度、散射和扩散尺度；支持导入 [自定义 PSF](PSF-FORMAT.md)。
- **桌面引力透镜**：实时扭曲盘面附近的桌面背景，范围随盘面形状缩放，外围平滑回到原背景。范围限制是视觉设计，不是真实引力的截止位置。
- **窗口行为**：始终置顶、鼠标穿透、隐藏、回到屏幕中央，以及单实例保护。

盘面的云团与颗粒是程序化材质，并非流体或固体尘埃模拟。光束细分、时间采样和光线积分均有数值近似，不能作为科研级辐射转移计算使用。

## 桌面采集与隐私

桌面引力透镜**每次启动默认关闭**。主动开启后需要 macOS 的屏幕录制许可；系统可能要求重启 App。

- 读取黑洞所在显示器的实时画面，可能包含其他窗口和通知；排除黑洞及其背景效果窗口，保留控制台和其他窗口的遮挡关系。
- 最多 30 FPS，不采集音频或鼠标指针。画面只在 App 内存中用于 CoreVideo／Metal 渲染，不保存、不上传。
- 关闭该功能、强度降至 0、隐藏黑洞或屏幕休眠时停止采集。暂停盘面动画时，已启用的桌面背景仍可实时更新。
- App 没有网络请求、遥测、自动更新、全局键盘监听或辅助功能授权流程。外观设置保存在 App 自己的 UserDefaults 中。
- 导入的 PSF 仅在当前进程中读取，不复制、修改或上传源文件。

系统录屏权限管理和提示以当前 macOS 为准。稳定的代码签名有助于系统识别更新，但不保证所有系统版本或证书轮换情况下都免于重新授权。

## 检查与已知限制

完整本地检查：

```sh
zsh Scripts/check.sh
```

检查只使用程序生成的图像，不截取真实桌面。它包含离屏渲染、光线与光束数值对照、镜头卷积、桌面合成、单实例策略、性能对照及打包签名验证。输出保存在被 Git 忽略的 `build/verification/`。较高分辨率的测试会占用较多 GPU 内存和时间。

测试说明和发布准备检查的实际范围见 [VERIFICATION.md](VERIFICATION.md)。刷新目标不等于实测帧率；大尺寸、高精度与桌面采集都会增加 GPU 开销。多显示器、Spaces、HDR 桌面及不同型号 Mac 的表现仍需要分别验证。
